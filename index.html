6 words to know · 六个词就够

percussion/pərˈkʌʃən/
n. 打击乐器

Instruments you hit to make a sound — like drums. The piano counts, because a hammer hits the strings.

“The piano is a percussion instrument.”

improviser/ˈɪmprəvaɪzər/
n. 即兴演奏者

Someone who makes up music while playing, without a written score.

“He was famous as an improviser.”

composer/kəmˈpoʊzər/
n. 作曲家

A person who writes music.

“Before he was famous as a composer…”

tempo/ˈtempoʊ/
n. 速度

How fast or slow the music goes.

“Her tempo can change in a second.”

precision/prɪˈsɪʒən/
n. 精确

Doing something exactly right, with no mistakes.

“The key is precision.”

underrated/ˌʌndərˈreɪtɪd/
adj. 被低估的

Not valued as much as you should be.

“I think he is underrated.”

01

Opening

0:00–0:18 · Slide 1

Good morning, everyone. / My name is Ma Mingyu. //

Today I want to talk about the piano — / differently. //

I'll show you four pianists, / and four different ways to press the same key. //

中速。前两句看观众。“four pianists”抬手指数；“the same key”放慢，停一拍再翻页。

02

The instrument

0:18–0:55 · Slide 2

Here is a surprising fact: / the piano is a percussion instrument. //

When I press a key, / I do not touch a string. / I move a small hammer. //

The hammer hits a string, / and the string sings. //

VIDEO ~10s / //

Eighty-eight keys. / One machine. //

But the machine is not the music. / The music is in how you press. //

说“hammer”时指屏幕。视频播放时退后半步，让观众看，不要说话。“One machine”压低音量；最后一句放慢。

03

Beethoven

0:55–1:30 · Slide 3

The first pianist is Beethoven. //

He was famous as an improviser / before he was famous as a composer. //

He played with such force / that he broke strings. //

When he lost his hearing, / he did not stop. //

He kept writing music / he could no longer hear. //

His music is a man hitting the piano / and refusing to apologize. //

For Beethoven, / the key is a weapon. ↘ //

“broke strings”加重；“no longer hear”放慢并停一拍；“weapon”不要喊，咬清楚、往下落。如果这页放视频，说完 weapon 后停 8 秒。

04

Argerich

1:30–2:05 · Slide 4

Second, Martha Argerich. //

She won the Chopin Competition in 1965. //

She still plays live / as if it were the first time. //

Her tempo can change in a second. / Her volume can go from a whisper / to an explosion. //

You never know what she will do next — / and that is why people buy tickets. //

She is not trying to be perfect. / She is trying to be alive. //

For Argerich, / the key is electricity. ↘ //

中段稍微加速，制造“不可预测”。说“whisper”时真的小声；“explosion”放开；“alive”放慢、加重。如果这页放视频，说完 electricity 后停 8 秒。

05

Lang Lang

2:05–2:40 · Slide 5

Third, Lang Lang. //

In 1999, / he was seventeen. //

A famous pianist was sick, / so he stepped in / at the Ravinia Festival — / that night. //

That night, / he became a star. //

Lang Lang plays with his whole body / and his whole face. //

But he brought classical music / to people who had never bought a ticket. //

For Lang Lang, / the key is theater. ↘ //

故事部分稍快，像讲八卦。“that night”上扬；说“whole body / whole face”时用手比一下。如果这页放视频，说完 theater 后停 10 秒。

06

Shen Wenyu

2:40–3:42 · Slide 6

slow Finally, Shen Wenyu. //

He was born in Chongqing in 1986 — / and he is why I wanted to give this talk. //

At sixteen, / he won second prize / at the Queen Elisabeth Competition / in Belgium. //

At eighteen, / he won first prize / at the Rachmaninoff Competition / in Los Angeles. //

His playing is not about show. / It is about control — / and precision. //

Every note in its place, / at a speed that seems impossible. //

He is less famous than Lang Lang. / I think he is underrated. //

I call him / the pianist's pianist. //

For Shen Wenyu, / the key is precision. / And for me, / that precision moves me the most. ↘ //

全场最慢。两场比赛的年份和名次说清楚，但不要赶。说“pianist's pianist”前停一拍，并且看着观众，不要看屏幕。如果这页放视频，最后停 14 秒。

07

Closing

3:42–4:10 · Slide 7

So: / Beethoven uses the piano as a weapon. / Argerich as electricity. / Lang Lang as theater. / Shen Wenyu as precision. //

Four people. / One instrument. //

The piano has eighty-eight keys — / but it does not have one sound. //

No two people / press them / the same way. ↘ //

Thank you. //

四个名字各停一拍。最后一句一字一顿。说完“Thank you”完全停住，不要补话，等主持人或老师接。

Q&A · 三个最可能的问题

Why Shen Wenyu?
Because his playing is honest. No show — just control. And I think he is underrated.

Is the piano a percussion or string instrument?
Both. The sound comes from strings, but a hammer hits them. So we play it like percussion.

Why these four?
I wanted four different ways to press one key — not a list of the top four.
